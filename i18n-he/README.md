# עברית ל-WordCraft (המאגר הזה)

הממשק של WordCraft מתורגם דרך [storytold/craft-i18n](https://github.com/storytold/craft-i18n):
הקטלוגים נקראים בזמן build ונארזים בתוך הקובץ (build-time, לא קבצי JSON בזמן ריצה).
עברית עוד לא נמצאת שם, ולכן היא נמצאת כאן — במאגר הזה — ונפרסת **מעל** ה-checkout של
craft-i18n בזמן הבנייה.

```
i18n-he/
  locales/he/common.tsv      מחרוזות משותפות לכל האפליקציות (כפתורים, יחידות, צבעים…)
  locales/he/wordcraft.tsv   מחרוזות של WordCraft עצמו (סרגל הכלים, תיבות דו-שיח, הודעות)
  tools/check.py             בדיקת התקינות של הקטלוגים (אותם כללים של craft-i18n)
  tools/assemble.py          בניית CRAFT_I18N_DIR ‏= craft-i18n + עברית
  tools/apply_code_overlay.py  ארבעת שינויי הקוד הקטנים שמוסיפים את עברית לאפליקציה
```

## איך זה עובד

1. `crates/ui-egui/build.rs` אורז את הקטלוגים מתוך `CRAFT_I18N_DIR` (משתנה סביבה — לא תלות Cargo).
2. `crates/ui-egui/src/i18n.rs` מציע את השפות שב-`LANGUAGES`; `he` נוסף שם.
3. `tools/assemble.py` מעתיק את `locales/` של craft-i18n ומוסיף עליו את `i18n-he/locales/he/`:

   ```sh
   python3 i18n-he/tools/assemble.py --craft-i18n ../craft-i18n --out .he-catalogs
   export CRAFT_I18N_DIR=$PWD/.he-catalogs CRAFT_I18N_REQUIRED=1
   cargo build --release
   ```

   בלי `--craft-i18n` נארזת רק עברית (אנגלית ועברית) — נוח לפיתוח.
4. מחרוזת שאין לה תרגום פשוט מוצגת באנגלית. קטלוג חלקי לא שובר build, טסט או release.

## מה מתורגם ומה עוד לא

`python3 i18n-he/tools/check.py --craft-i18n ../craft-i18n` מדפיס כמה שורות יש בכל קובץ
והאם יש שורות שאפליקציה כבר לא מבקשת. המצב ההתחלתי: כ-880 שורות ב-`wordcraft.tsv` וכ-520
ב-`common.tsv` — התוויות הקצרות והנפוצות של הממשק (סרגל הכלים, תפריטים, צבעים, יחידות,
כפתורים). מחרוזות ארוכות של תיבות דו-שיח, הודעות שגיאה ופסקאות הסבר עדיין באנגלית.

## איך מוסיפים או מתקנים תרגום

שורה אחת לכל מחרוזת, שלושה טורים מופרדים ב-TAB:

```
<TAB>English source text<TAB>תרגום בעברית
```

* מקור אנגלי הוא המפתח — חייב להיות זהה למחרוזת בקוד, אות באות.
* `\n` (מעבר שורה), `\t` ו-`\\` הם הבריחות היחידות.
* `{name}` חייב להופיע גם באנגלית וגם בעברית; `…` בסוף — בשניהם או בשניהם לא.
* `@plural` — באנגלית `one|other`, בעברית ארבע צורות מופרדות ב-`|`:
  `one|two|many|other` (למשל `{n} פריט|{n} פריטים|{n} פריטים|{n} פריטים`).
* `@id language.name` — השם `עברית`, כדי שבורר השפות יציג אותו נכון.
* שורה שזהה בדיוק לשורה ב-`common.tsv` היא שגיאה (היא לא משנה כלום).

אחרי עריכה: `python3 i18n-he/tools/check.py` ואז commit. אין צורך לגעת בקוד.

## אוטומציה: כל יום מהמאגר המקורי

`.github/workflows/sync-upstream.yml` רץ כל יום ב-04:17 UTC (וגם ידנית):

1. מושך את `storytold/wordcraft@main` העדכני וממזג אותו ל-`main` של המאגר הזה.
   אם יש קונפליקט באחד משלושת הקבצים שהשכבה הזאת נוגעת בהם — נלקחת הגירסה של המאגר
   המקורי והשכבה מוחלת שוב (`tools/apply_code_overlay.py`). קונפליקט בכל קובץ אחר עוצר את
   הריצה, כדי שאדם יסתכל.
2. בודק את הקטלוגים (`tools/check.py`), בונה את הקטלוגים המשולבים ובונה את האפליקציה ל-Linux
   (tar.gz + AppImage) עם עברית בפנים.
3. אם לגירסה (מ-`Cargo.toml`) עוד אין release במאגר הזה — מפרסם release בתג
   `v<גירסה>-he.1` עם קובצי ה-build ו-`SHA256SUMS.txt`. אם הגירסה כבר פורסמה, ה-build נשאר
   כ-artifact של הריצה.

כך הגירסה כאן אף פעם לא מתיישנת: היא תמיד `main` של המאגר המקורי ועוד עברית, ובנויה מחדש.

## מה עוד חסר

* **פריסת ממשק מימין לשמאל.** כל תווית עברית נפרסת נכון מימין לשמאל (epaint עושה bidi),
  אבל סרגל הכלים, החלוניות והתפריטים עדיין מסודרים משמאל לימין.
* **הגהה בעברית** (איות/דקדוק) — `wordcraft-proof` לא תומך בעברית.
* **תרגום מלא** — ראו „מה מתורגם ומה עוד לא” למעלה.
* **פונטים**: ל-Inter אין אותיות עבריות, ולכן הממשק שואל גופן עברי מהמערכת (Noto Sans Hebrew,
  Segoe UI, Arial Hebrew…) כגופן גיבוי — בדיוק כמו שהכיתוב של חלון הקובץ עושה היום. ב-build
  עם craft-fonts הגופנים של המערכת עדיין נדרשים לעברית.
